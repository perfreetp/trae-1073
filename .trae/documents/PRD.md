## 1. 产品概述

城市消防隐患治理 Web 应用是一套服务于街道消防专干、物业管理人员和消防监督人员的综合管理平台。通过数字化手段实现消防隐患的全流程闭环管理，提升消防安全监管效率，降低火灾风险。

- 核心目标：实现消防隐患从发现、登记、整改、复查到归档的全流程数字化管理
- 目标用户：街道消防专干、物业管理人员、消防监督执法人员
- 市场价值：助力城市消防安全精细化管理，打通监管"最后一公里"

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 街道消防专干 | 管理员创建 | 风险地图查看、单位档案管理、检查计划制定、隐患督办、数据分析 |
| 物业管理人员 | 管理员创建 | 物业自查填报、隐患整改上报、培训签到、疏散演练记录 |
| 消防监督人员 | 管理员创建 | 执法检查、红黄牌标记、举报核查、监管报表导出 |

### 2.2 功能模块

1. **风险地图**：区域风险热力图、重点场所标注、隐患分布可视化
2. **单位档案**：重点场所建档、消防设施登记、基本信息管理
3. **检查计划**：检查表配置、计划制定、到期提醒
4. **隐患整改**：现场拍照取证、隐患等级判定、整改责任分派、复查闭环
5. **宣传培训**：培训计划、签到管理、考试测评、疏散演练记录
6. **举报受理**：群众举报登记、流转分派、处理反馈
7. **数据分析**：重复隐患识别、逾期督办、红黄牌标记、区域排行、监管报表导出

## 3. 核心流程

### 3.1 隐患整改闭环流程

消防检查人员发现隐患后，现场拍照取证并录入系统，系统根据隐患类型和严重程度自动判定风险等级，然后分派给相关物业或单位责任人限期整改。整改完成后责任人提交整改报告和照片，检查人员进行现场复查，复查通过则隐患闭环归档，不通过则重新分派整改。

```mermaid
flowchart LR
    A["发现隐患"] --> B["现场拍照取证"]
    B --> C["隐患等级判定"]
    C --> D["分派整改责任"]
    D --> E["责任人整改"]
    E --> F["提交整改报告"]
    F --> G["复查验证"]
    G --> H{是否通过?}
    H -->|是| I["闭环归档"]
    H -->|否| D
```

### 3.2 举报处理流程

群众通过举报渠道提交消防隐患线索，受理人员登记举报信息并分派给辖区消防专干进行现场核查。核查属实的按隐患整改流程处理，不属实的记录原因并反馈举报人。

```mermaid
flowchart LR
    A["群众举报"] --> B["受理登记"]
    B --> C["分派核查"]
    C --> D["现场核查"]
    D --> E{是否属实?}
    E -->|是| F["进入隐患整改流程"]
    E -->|否| G["记录原因"]
    F --> H["反馈举报人"]
    G --> H
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：消防红（#E53935）作为主色调，搭配深蓝（#1565C0）作为辅助色，体现消防专业属性
- **中性色**：以深灰为底色，白色为卡片背景，确保信息清晰可读
- **按钮风格**：采用圆角矩形按钮，主按钮使用消防红渐变，悬停时有阴影和缩放效果
- **字体**：标题使用思源黑体 Bold，正文使用思源黑体 Regular，确保中文显示美观
- **布局风格**：采用左侧导航 + 顶部工具栏 + 主内容区的经典后台布局，卡片式信息展示
- **图标风格**：使用线性图标，保持简洁统一，重要操作使用填充图标突出

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 风险地图 | 热力图区域 | 全屏地图展示，右侧悬浮控制面板，支持图层切换 |
| 风险地图 | 统计卡片 | 顶部悬浮关键指标卡片，带数字动画效果 |
| 单位档案 | 列表区域 | 表格 + 筛选栏，支持分页、排序、批量操作 |
| 单位档案 | 详情面板 | 右侧滑出式详情面板，标签页切换不同信息模块 |
| 检查计划 | 日历视图 | 月/周视图展示检查计划，不同颜色区分状态 |
| 隐患整改 | 时间轴 | 隐患处理全流程时间轴展示，清晰追踪进度 |
| 数据分析 | 图表区域 | 多种图表类型（柱状图、饼图、折线图）组合展示 |
| 数据分析 | 排行列表 | 带进度条的排行榜，支持切换统计维度 |

### 4.3 响应式

- 采用桌面优先设计，针对 1920×1080 分辨率优化
- 适配 1366×768 及以上主流分辨率
- 表格区域支持横向滚动，保证小屏幕下内容可查看
- 关键操作按钮在各种分辨率下保持可点击区域

### 4.4 动效设计

- 页面切换采用淡入淡出过渡动画
- 数据加载使用骨架屏占位
- 图表数据展示使用渐进式动画
- 悬停状态有轻微缩放和阴影变化
- 通知提醒采用右上角滑入动画
